# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI. The objective is to understand customer purchasing patterns, identify revenue-driving factors, and generate business insights through data analysis and visualization.

## Dataset

The dataset contains customer demographics, purchase details, product categories, subscription information, payment methods, discounts, and customer review ratings.

## Tools Used

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* MySQL
* Power BI
* Gamma

## Project Steps

### 1. Data Loading

* Imported the dataset into Python.
* Explored dataset structure and data types.

### 2. Data Cleaning

* Checked for missing values.
* Removed duplicates.
* Validated data types.
* Prepared data for analysis.

### 3. Exploratory Data Analysis (EDA)

* Customer demographic analysis.
* Revenue analysis by category, gender, and age group.
* Subscription and discount analysis.
* Seasonal purchase trend analysis.
* Product performance analysis.
* Data visualization using charts and graphs.

### 4. SQL Analysis

* Revenue analysis.
* Customer segmentation.
* Product performance analysis.
* Subscription behavior analysis.
* Discount effectiveness analysis.
* Customer loyalty analysis.

### 5. Dashboard Creation

* Built an interactive Power BI dashboard.
* Created KPIs for revenue, customers, average purchase amount, and ratings.
* Added category, demographic, product, and seasonal analysis visuals.
* Implemented interactive filters and slicers.

### 6. Presentation

* Summarized key findings and business recommendations.
* Created a presentation using Gamma for stakeholder communication.

## Key Results

* Identified top-performing product categories.
* Analyzed customer spending patterns across different demographics.
* Evaluated the impact of subscriptions and discounts on revenue.
* Identified high-value customer segments.
* Discovered seasonal trends influencing customer purchases.

## How to Run

1. Load the dataset into Python.
2. Execute the data cleaning and EDA notebook.
3. Import the dataset into MySQL and run SQL queries.
4. Import the dataset into Power BI and build the dashboard.
5. Review the Gamma presentation for project findings.
